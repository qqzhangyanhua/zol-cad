# 信任模型：整图质量分级 + 高风险字段强制复核，不做逐字段置信度

输入图纸质量参差（约一半规范 PDF、一半扫描/截图），如果 AI 对糊图和清晰图给出"看起来一样自信"的结果，报价员被坑一次就会永久丧失信任。因此需要一个"诚实表达把握程度"的机制。

**决定**：MVP 采用两层机制，而非逐字段置信度：
1. **整图质量分级**：上传后对整张图评级，差图劝退并建议人工，好图才自动预填。
2. **高风险字段强制复核规则**：尺寸、公差等高风险字段类型，无论图纸质量如何一律标记"需确认"，堵住"清晰图上个别错读公差"这一致命缝隙。

**为什么不做逐字段置信度**：逐字段置信度需要模型输出可信度且校准可靠，否则会更误导；成本高、MVP 阶段不划算。用"按字段类型的一条固定规则"以极低成本守住信任底线，是刻意的简化。将来若需要更细的把握度表达，可在此基础上演进。

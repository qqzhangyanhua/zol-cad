# 风险标签：规则引擎生成，且永不输出"无风险"

风险提示（高精度、深孔、薄壁、细长等）是本产品区别于普通 OCR 工具的差异化卖点，但它本质上是"判断"，而 ADR-0001 已把判断划出范围、且大模型在判断上最容易一本正经地胡说。

**决定**：
1. **规则引擎生成，不让大模型直接判断风险**。大模型只负责提取结构化数据（关键尺寸、公差等），风险一律由基于这些数据的规则算出（如"公差 ≤ IT6 → 高精度"、"孔深/孔径 > 5 → 深孔"）。理由：可解释、可调、可随工厂经验积累规则库，且不违背 ADR-0001 的边界。
2. **永不输出"无风险/安全"结论**。风险标签只表达"发现的疑似风险，请复核"，绝不表达"此件无风险"。

**为什么第 2 条是硬不变量**：一个错误的"无深孔风险"会让报价员不上浮报价而亏本——这是比漏提尺寸更危险的**沉默错误**，因为它直接作用于定价决策。因此宁可只报发现的疑似风险、不报安全。将来若有人想"补全"成显示安全状态，本条即为反对依据。

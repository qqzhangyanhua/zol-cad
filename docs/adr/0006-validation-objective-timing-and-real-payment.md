# 验证方法：客观埋时 + 真实收款，而非主观印象

MVP 以"验证价值"为目的，若无内建测量手段，三个月后只会得到"感觉还行"这类无法证伪的主观印象。

**决定**：
- **省时用客观数据证明**：系统自动记录每张图"上传 → 已复核"的处理耗时；种子用户在试用初期手工计时几张纯人工作业作为基线，两者对照算出真实节省。这给产品加了一个硬需求——**每次处理必须留关键时间戳**。
- **付费意愿用真实收款证明**：三个月内真的向种子工厂收取小额试用费（象征性金额即可）。目的不是赚钱，而是逼出真实信号——口头"愿意付费"信息量几乎为零，只有触发真实付款动作才算验证成立。

**被否决的替代**：纯主观问卷（不可证伪）、只收书面意向不收款（弱于真实付款）、试用期全免费（无法验证"值不值得买"，只验证了"好不好用"）。

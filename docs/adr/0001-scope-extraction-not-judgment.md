# 聚焦"读图取数"，不做报价判断；只提成本驱动的关键尺寸

产品定位为服务型机加工厂的报价辅助入口。经拷问确认：工厂报价的瓶颈中，可被软件**确定性替代**的部分是"读图取数"（提取标题栏字段、关键尺寸公差、技术要求并结构化），而报价判断（估工时、定价、排工艺）短期内 AI 做不好也不敢让用户信，因此**判断类工作仍归人**，不纳入范围。

在"取数"内部进一步收窄：**只提取驱动成本的少数关键尺寸与公差，不追求还原全图所有标注**。理由是全图尺寸提取正是 AI 准确率最差、错误代价最高、人工核对最累的区域；而报价判断真正需要的输入通常只是几个成本驱动特征。

这条同时定义了大量"不做"的边界（自动定价、工艺路线生成、全图尺寸还原），是难以逆转的范围基石。

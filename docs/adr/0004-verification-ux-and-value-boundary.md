# 复核体验：表单 + 原图并排 + 显式提示；MVP 不承诺替代看图

纯大模型提取会**漏提**（图上最严公差/最深孔根本没被提出来），而漏提无法被"需确认"标记——你不能对一个不存在的字段打标记。因此复核体验必须在承诺上诚实。

**决定**：MVP 采用表单与原图并排显示，并显式提示"本工具不替代看图，请重点复核公差密集区与技术要求"。**不做**坐标级视觉定位（bounding box 框选），因为大模型返回的坐标不稳、投入产出比在 MVP 阶段差。

**价值主张边界**：MVP **不承诺**替代人工看图。对外价值改述为"少抄写、看得更快"，而非"不用看图"。漏提作为已知限制，防御靠"并排原图 + 显式提示 + 人自查"。

**演进**：待付费验证成立，再引入图文联动的视觉定位（点提取值高亮到图上来源位置、暴露未覆盖区域），把漏提防御从"靠自觉"升级为"可见"。

# MVP 质量承诺收窄到一个目标零件族

"机加工零件图"横跨差异极大的族类（回转体车件、棱柱铣削件/箱体、钣金、模具件……），它们的标题栏习惯、常见公差、风险模式、底稿字段都不同。通吃会让提取提示词、风险规则库全面稀释，demo 不惊艳。

**决定**：先取 2~3 家目标工厂的真实图纸样本看分布，快速收敛，把 MVP 的**质量承诺收窄到一个主力零件族**；其余族类允许上传但标注"实验性、不保证"。

**理由**：
- 针对特定族类的提示词（"这是车削回转体，请关注外圆/内孔/长度公差"）准确率明显高于泛化提示。
- 风险规则（ADR-0007 的深孔/薄壁/细长判定）与零件族强相关，聚焦才能做深。
- 收窄后种子客户画像更清晰（找"主要做这类件"的厂），demo 更聚焦。

不凭空拍脑袋选族类（用真实样本决定），也不通吃（会稀释一切）。这是验证期的聚焦策略，验证成立后可再扩族。

## 调研执行备注（框架）

票 01 的**调研框架与填空模板**已落在：

`.scratch/mvp-quote-assistant/research/01-target-part-family/`

内含：样本库存、族类分布统计表、关键尺寸清单、风险标签规则草案（条件+阈值格式）、fixture 图集槽位、人工标注模板。

**本 ADR 的决定不变**：目标零件族仍须由 2~3 家目标工厂真实零件图样本的分布选定。框架内凡结论、族类选定、规则阈值、fixture 标注，在样本到位前一律标记为「待真实样本」，不得用猜测值或示例数字定稿。ADR-0007 中的阈值句式仅作规则格式参考，不构成本 ADR 对具体门槛的确认。

样本收集与统计完成并选定族类后，再把选定族名称与样本依据回写本节或另开 ADR 修订记录。

# 数据保密：MVP 用境内合规云，私有化作为后续选项

机加工厂的客户零件图普遍涉密（常有 NDA）。而 ADR-0003 决定把整张图上传给第三方多模态大模型，两者直接冲突：只要工厂/其客户担心"图纸出厂、被用于训练、泄密担责"，采购就可能在安全问卷环节谈崩，与识别准确率无关。

**决定**：
- **MVP 实现纯云 SaaS**，选用**数据在境内、书面承诺不用于训练、可签 DPA**的国内企业级大模型，把"保密"从技术问题转化为合同问题正面回应。
- **私有化/本地部署**不在 MVP 实现，仅作为面向大客户的销售话术与后续选项，记录意向；出现真正愿为此付费的大客户再投入。
- 模块 7 的角色权限只解决"内部越权访问"，本 ADR 解决更根本的"数据出厂上第三方云"顾虑，二者互补不可互相替代。

**下游约束**：反向收紧了 ADR-0003 的供应商筛选标准（境内 + 不训练 + 可签约为硬门槛）。

# 14 — 报价底稿导出

**What to build:** **报价员**在**报价任务**上点一次导出，拿到一份每个零件一行的**报价底稿**（xlsx / csv），直接用于内部核算或对外报价。这份表长得就像这家工厂现在用的那份，不需要再手工搬一次列。

**字段模板不做自助配置 UI。** 每家工厂的映射模板在 onboarding 时由团队按其现有底稿手工配好，作为一份后台配置存在，不出现在**管理员**界面里。这是"服务代替功能"的刻意取舍：字段映射 UI 要引入一整套映射概念（源字段、目标列、缺省值、顺序），成本高，而每家工厂一辈子只用一次。

导出内容里**必须带上风险标签**——否则报价员在界面上看到的加工难点会在最后一步悄悄丢失，而定价恰恰发生在这张表上。非**目标零件族**的实验性标记同理，下游看表的人需要知道哪几行更不可靠。

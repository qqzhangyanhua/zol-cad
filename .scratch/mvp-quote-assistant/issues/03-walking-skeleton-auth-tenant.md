# 03 — 走通骨架：登录后看到空的零件图列表

**What to build:** **报价员**用账号登录，进入系统后看到一个"你还没有上传过零件图"的空列表；退出登录后无法访问该页面。这是整个产品第一条能跑通的端到端路径。

这一票同时把两个库的地基立起来：后端 FastAPI 骨架与四层分层（接口层 / 用例层 / 领域层 / 适配器层）、Postgres 与 Alembic、缝 1 的 pytest + ASGI 测试基座、前端 Next.js 骨架与 BFF 代理。

**租户隔离必须在这一票里做完**，不能留到后面的权限票。所有数据以工厂为租户边界，租户过滤在用例层统一施加、不依赖调用方传参。理由很实际：等到十几个用例都写完再回头补租户过滤，是这个项目里最容易漏、漏了后果最严重的一类改动——漏一处就是 A 厂看见 B 厂客户的图纸。

**Blocked by:** None — can start immediately.

**Status:** claimed

- [ ] **报价员**能用账号密码登录，未登录访问受保护页面被挡回登录页
- [ ] 登录后看到空的**零件图**列表页，文案说明还没有内容
- [ ] 后端按四层分层落地，依赖方向只能向内；领域层无 IO
- [ ] Postgres 与 Alembic 就位，迁移可正向执行
- [ ] 缝 1 测试基座可用：pytest 加 FastAPI 的 ASGI 测试客户端直接打进应用，不起真实网络端口
- [ ] 测试跑在容器化的真实 Postgres 上，启动时真实执行一遍 Alembic 迁移

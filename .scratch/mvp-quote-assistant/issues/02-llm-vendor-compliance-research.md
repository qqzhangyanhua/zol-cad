# 02 — 多模态大模型供应商合规调研

**What to build:** 选定 MVP 的多模态大模型供应商，并把结论落成一条 ADR。

**调研顺序不可颠倒**：先用三条硬门槛筛掉不合格者，再在剩下的里面比识别效果。ADR-0003 与 ADR-0005 明确写了这三条**先于识别效果**——一个识别率再高但不肯签 DPA 的供应商，会让采购在工厂的安全问卷环节直接谈崩，与效果无关。

三条硬门槛（缺一即一票否决）：数据存储在境内、书面承诺不用于模型训练、可签数据处理协议（DPA）。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 列出候选的境内企业级多模态大模型供应商
- [ ] 逐家核实三条硬门槛，证据是**白纸黑字的条款或书面答复**，不是销售口头承诺
- [ ] 不满足任一门槛的供应商被排除，并记录排除原因（将来有人重提时能直接引用）
- [ ] 在通过门槛的供应商之间，用票 01 的真实样本做识别效果对比，对比维度覆盖**标题栏**字段、**关键尺寸**与公差、技术要求
- [ ] 记录每家的单张调用成本，给出成本估算
- [ ] 确认选定供应商的可用区域，与阿里云 OSS 的区域对齐（避免图纸跨区流动带来额外的合规解释成本）
- [ ] 结论落成一条新 ADR，写明选定谁、三条门槛各自的证据、被排除者与排除原因

# 02 — 多模态大模型供应商合规调研

**What to build:** 选定 MVP 的多模态大模型供应商，并把结论落成一条 ADR。

**调研顺序不可颠倒**：先用三条硬门槛筛掉不合格者，再在剩下的里面比识别效果。ADR-0003 与 ADR-0005 明确写了这三条**先于识别效果**——一个识别率再高但不肯签 DPA 的供应商，会让采购在工厂的安全问卷环节直接谈崩，与效果无关。

三条硬门槛（缺一即一票否决）：数据存储在境内、书面承诺不用于模型训练、可签数据处理协议（DPA）。

**Blocked by:** None for starting the compliance screen. **Remaining acceptance work is blocked on (1) written DPA / processing-location replies for vendors that are not already G2-rejected, and (2) ticket 01 real factory samples**（识别对比 / 选定供应商 / 关闭 ADR-0009 不可凭空完成）.

**Status:** ready-for-human

**Research framework:** `.scratch/mvp-quote-assistant/research/02-llm-vendor-compliance/`（公开条款核验已落地；识别对比与选定仍 blocked；见该目录 `README.md`）

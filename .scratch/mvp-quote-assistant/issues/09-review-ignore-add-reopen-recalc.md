# 09 — 复核补全：忽略、补录、重开、风险重算

**What to build:** 把**复核**从"能用"补齐到"够用"。**报价员**能把图上不适用的条目标记为"忽略"，让它不再挡着完成复核；能手工补录一条 AI 完全没提出来的**关键尺寸**，让漏提的项也进入最终结果；能在标记"已复核"之后重新打开修改。修正数据后**风险标签**跟着重算，标签始终反映报价员确认过的值，而不是 AI 的原始输出。

其中**手工补录**是对漏提的正面应对。ADR-0004 已承认漏提是已知限制且无法被"需确认"标记覆盖——你不能对一个不存在的字段打标记——所以至少要让报价员自己发现后能补进来，而不是只能记在纸上。

**重试提取不覆盖已有修改**这一条放在这里，因为它要等修改行为存在之后才谈得上。

## Comments

实现已落在 PR：https://github.com/qqzhangyanhua/zol-cad/pull/9

设计要点：

- 忽略是字段级状态。`unfinished_confirmation_items` 排除已忽略项，因此忽略不阻塞已复核；界面仍展示，可撤销。忽略项不参与风险标签。
- 补录走 `POST /part-drawings/{id}/fields`。空的关键尺寸槽写入原位并标 `source=added`；槽位已有值则追加 `kind__added__N`，与提取项同等对待。报价底稿导出是票 14，本票把补录项留在同一份 `extracted_fields` 里，风险标签已经按角色纳入。
- 已复核 → 复核中 可重开。已复核时确认 / 修改 / 忽略 / 补录一律 409，必须先重开。再标记已复核仍走领域层「无未处理需确认项」。
- 风险标签按当前确认值现算：修正后跟新值走，忽略项不参与，补录项映射回同一角色。
- 已提取 / 复核中可重试。`merge_extraction_preserving_review` 保留已确认、已忽略、补录项，未改过的槽位用新提取覆盖。
- 不做票 10（修正记录）。重开后的「改动留痕」本票指改动保留在结果里，不写修正记录实体。

# 09 — 复核补全：忽略、补录、重开、风险重算

**What to build:** 把**复核**从"能用"补齐到"够用"。**报价员**能把图上不适用的条目标记为"忽略"，让它不再挡着完成复核；能手工补录一条 AI 完全没提出来的**关键尺寸**，让漏提的项也进入最终结果；能在标记"已复核"之后重新打开修改。修正数据后**风险标签**跟着重算，标签始终反映报价员确认过的值，而不是 AI 的原始输出。

其中**手工补录**是对漏提的正面应对。ADR-0004 已承认漏提是已知限制且无法被"需确认"标记覆盖——你不能对一个不存在的字段打标记——所以至少要让报价员自己发现后能补进来，而不是只能记在纸上。

**重试提取不覆盖已有修改**这一条放在这里，因为它要等修改行为存在之后才谈得上。

**Blocked by:** 08, 07

**Status:** claimed

- [ ] **报价员**能把某一项标记为"忽略"，被忽略项不阻塞标记"已复核"
- [ ] 被忽略项在界面上仍可见、可撤销忽略
- [ ] **报价员**能手工补录一条 AI 未提出的**关键尺寸**，补录项与提取项在后续流程中同等对待
- [ ] 补录项在导出与**风险标签**计算中都被纳入
- [ ] 修正任一**关键尺寸**或公差后，**风险标签**基于确认后的值重算
- [ ] 已标记"已复核"的**零件图**可重新打开修改，改动留痕
- [ ] 重开后再次标记"已复核"仍需满足"无未处理需确认项"的条件
- [ ] 重试提取时，已经做过的**复核**修改不被覆盖
- [ ] 缝 1 有测试证明：修正关键尺寸后风险标签随之变化、重试不冲掉已有修改

# 16 — 本厂数据导出与删除

**What to build:** **管理员**能把本厂的全部数据一次性导出，也能彻底删除——合作终止时数据可以带走或清除。

这不是可有可无的合规装饰。机加工厂的客户**零件图**普遍涉密、常带 NDA，而 ADR-0005 决定把图纸上传到第三方云。工厂能不能拿回和清掉自己的数据，是采购谈判里会被直接问到的问题；答不上来，成交就卡在安全问卷环节，跟识别准确率没有关系。

**Blocked by:** 04

**Status:** claimed

- [ ] **管理员**能导出本厂全部数据，含**零件图**原文件、提取结果、**复核**结果、**风险标签**、**报价任务**、**修正记录**
- [ ] 导出格式可被人和程序读取，不是黑盒
- [ ] **管理员**能发起删除本厂全部数据，需要二次确认
- [ ] 删除同时清除对象存储中的原图文件，不留孤儿文件
- [ ] 删除后再登录看不到任何残留数据
- [ ] 导出与删除都严格限定在本厂租户边界内
- [ ] 缝 1 有测试证明：删除 A 厂数据后 B 厂数据完好无损

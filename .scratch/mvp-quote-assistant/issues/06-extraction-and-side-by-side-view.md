# 06 — 读图取数与并排展示提取结果

**What to build:** **报价员**打开一张已分级的**零件图**，看到左边是预填好的提取结果表单、右边是原图的并排界面。表单里已经填好**标题栏**字段（图号、零件名称、材料、数量）、**关键尺寸**与公差、以及技术要求（热处理、表面处理、粗糙度等），按字段类别分组展示。

这一票只做展示，逐项确认与修改留到票 08。

有两条产品承诺必须在这里兑现。一是**图上没有的字段如实留空**，不编造一个看起来合理的值——空值本身就是一个可信信号，编造出来的值则会直接毁掉信任。二是"本工具不替代看图，请重点复核公差密集区与技术要求"的提示常驻可见（ADR-0004）：纯大模型提取会**漏提**，而漏提无法被"需确认"标记——你不能对一个不存在的字段打标记，所以 MVP 对漏提的唯一防御就是并排原图加这句提示加人自查。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 分级完成后自动触发**读图取数**，界面显示提取进行中的状态
- [ ] 提取完成后展示左表单右原图的并排界面，原图区可缩放平移
- [ ] 提取出**标题栏**字段：图号、零件名称、材料、数量
- [ ] 提取出驱动成本的**关键尺寸**与公差（最严公差、最大外形、最深孔、最薄壁等）
- [ ] 提取出图面技术要求
- [ ] 每一项都标明所属字段类别（**标题栏**字段 / **关键尺寸** / 技术要求），可按类别快速扫过
- [ ] 图上没有的字段如实留空，不填编造值
- [ ] "本工具不替代看图，请重点复核公差密集区与技术要求"的提示常驻可见，不可关闭
- [ ] 提取引擎返回结果在适配器边界上做严格校验，校验不通过按提取失败处理，脏数据不进领域层
- [ ] 提取失败时展示失败原因，提供一键重试，重试不需要重新上传
- [ ] 状态机扩展：提取中 → 已提取，失败进入"提取失败"、可重试回"提取中"

# 风险标签规则草案（条件 + 阈值）

**状态：** 规则槽位与格式就绪；**阈值一律待真实样本**（blocked）  
**依赖：** 选定族（`02`）+ 关键尺寸清单（`03`，规则输入字段须能被提取）  
**约束：** 规则引擎生成风险标签；永不输出「无风险/安全」（ADR-0007）

## 格式约定

每条规则必须写成：

```text
当 <判定条件，引用已提取字段> 满足 <阈值或比较> → 打上 <风险标签名>
```

登记表字段：

| 列 | 含义 |
|----|------|
| 规则 ID | 稳定标识，如 RL-DEEP-HOLE |
| 风险标签名 | 展示给报价员的短名（如「深孔」） |
| 判定条件（字段） | 依赖哪些关键尺寸/提取值 |
| 阈值 / 比较 | 数值或等级门槛；**样本前禁止定稿** |
| 说明（给报价员展开用） | 一句话解释为何算疑似风险 |
| 优先级（展示序） | 整数；可先空着，管理员可调（票 07/15） |
| 样本依据 | 支撑该阈值的样本 ID 或厂方经验备注 |
| 状态 | `blocked` / `draft` / `accepted` |

空结果语义（产品文案，不因本草案改变）：「未发现可判定的风险项，不代表此件无风险」。

标签名来自领域已讨论的常见项（高精度、深孔、薄壁、细长等）。是否采用、阈值多少、是否增删，均 **待真实样本 + 选定族** 之后决定。

|---------|------------|------------------|-------------|------------------|--------|----------|------|
| RL-HIGH-PREC | 高精度 | 待真实样本（如最严公差等级/数值） | 待真实样本 | 待真实样本 | 待真实样本 | 待真实样本 | blocked |

| RL-SLENDER | 细长 | 待真实样本（如长度与直径） | 待真实样本 | 待真实样本 | 待真实样本 | 待真实样本 | blocked |

## 与关键尺寸的映射检查（选定后填）

| 规则 ID | 依赖的关键尺寸 ID（见 03） | 字段缺失时行为 |
|---------|---------------------------|----------------|
| 待真实样本 | 待真实样本 | 不触发该标签（沉默 ≠ 安全） |

## 定稿检查

- [ ] 每条规则都是「条件 + 阈值 → 标签」，无模型主观判断句
- [ ] 无「无风险 / 安全」类输出路径
- [ ] 阈值均有样本或厂方书面/口述记录依据（依据写在「样本依据」列）
- [ ] 草案可供票 07 风险规则引擎直接翻译成可执行规则

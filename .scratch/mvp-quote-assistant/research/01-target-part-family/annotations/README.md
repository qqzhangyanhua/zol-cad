# 人工标注模板说明

**状态：** 模板就绪；具体标注 **待真实样本**（blocked）

## 用法

1. 在 `05-fixture-atlas.md` 为某槽位选定真实样本后，复制 [`_TEMPLATE.md`](./_TEMPLATE.md) 为 `fixtures/<槽位 ID>.md`。
2. 由人对照原图填写期望提取结果；空值表示「图上确实没有」，禁止编造看似合理的值。
3. 关键尺寸行的类型名称须与 `../03-critical-dimensions.md` 定稿 ID/名称一致（族未定时可先按图面如实写，定稿后回填对齐）。
4. 风险标签**不是**标注里手写结论：标注只提供结构化提取期望值；风险由规则引擎按 `04` 计算。可在「预期会触发的规则（供对照）」中可选填写，仍标待真实样本直至规则阈值定稿。

## 质量档与族类

与图集一致：

- 图纸质量分级：`清晰` | `一般` | `差`
- 族类槽：`目标族` | `非目标族`（选定前写粗标族类名，选定后改槽位类型）

## 目录

| 路径 | 说明 |
|------|------|
| `_TEMPLATE.md` | 单份标注空白模板 |
| `fixtures/` | 每张 fixture 的标注实例（当前仅占位，无虚构内容） |

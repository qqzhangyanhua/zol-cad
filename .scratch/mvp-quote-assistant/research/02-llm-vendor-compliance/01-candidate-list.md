# 候选清单

**状态：** 已列出公开可查的境内企业级多模态产品线  
**判定：** 本表只回答「谁进入门槛筛」；谁过门槛见 `02-hard-gates-matrix.md`。

列入标准：

- 主体在中国大陆运营，或提供中国站企业 API；
- 公开提供**图像理解 / 视觉理解**（读图取数需要把零件图页交给模型）；
- 面向企业或开发者的 API / 云平台，而不是仅 C 端聊天 App。

未列入：境外主体的 Claude / GPT / Gemini 直连（ADR-0005 要求境内企业级）。经境内云转售的三方模型，按**实际处理该次推理的服务协议**计，不按品牌名自动过关（见阿里云百炼协议 6.2.9）。

**调研日期：** 2026-08-25

## 硬约束（不可违反）

1. **调研顺序不可颠倒** — 先用三条硬门槛筛掉不合格者，再在剩下的里面比识别效果（ADR-0003 / ADR-0005）。不得用识别率回过头来放过未过门槛的供应商。
2. **门槛证据必须是白纸黑字** — URL + 可核对引文。销售口头、博客转述、帮助中心与服务协议冲突时，以服务协议为准；冲突本身记为「证据不足」，不得记「通过」。
3. **不编造票 01 样本上的识别结果** — 真实零件图样本尚未入库（见 `.scratch/mvp-quote-assistant/research/01-target-part-family/`）。识别对比表一律留「待票 01 真实样本」。
4. **不在证据不齐时点名选定供应商** — 三条门槛对某一家都有书面证据之前，不得写「选定 X」。即使某家门槛表面上齐，没有样本对比也不得关闭 ADR。

三条硬门槛（缺一即一票否决）：

| # | 门槛 | 本调研的判定口径 |
|---|------|------------------|
| G1 | 数据存储在境内 | 必须写明**客户业务数据 / 输入内容**在中华人民共和国境内（大陆）存储或处理。仅写「个人信息境内存储」、或「由客户自选区域」、或「使用许可限于大陆」而没有处理地点，记「证据不足」或「有条件」，不得无条件通过。中国香港不计入「境内/大陆」。 |
| G2 | 书面承诺不用于模型训练 | 必须有**肯定句**：「不会用客户输入/输出训练或改进模型」。没有授权条款 ≠ 书面承诺。帮助页与协议打架 → 证据不足。默认授权训练 / 匿名化后可训练 / 用于「模型服务优化」→ 未过。 |
| G3 | 可签数据处理协议（DPA） | 必须有**适用于该产品、中国站主体**的公开 DPA / 数据处理附则 / 数据保护协议，或供应商书面答复「可签」。国际站 DPA、其他产品的 DPA、服务协议里的一般数据条款，均不替代。 |

## 执行顺序（不可颠倒）

1. 列出境内企业级多模态候选（`01`）。
2. 只根据公开书面条款做 G1/G2/G3（`02` + `evidence/`）。未过或证据不足的写入 `03`。
3. 对门槛未决的候选发出 `06` 的书面问询，把回函原文贴进 `evidence/` 后再改判定。
4. **仅当**至少一家三门槛均为「通过」或「有条件通过且条件已落实」时，才用票 01 真实样本填 `05`。
5. 对比完成后再写 ADR-0009 的「选定谁」；此前 ADR-0009 只是模板。

## 当前结论（诚实）

- **没有**一家供应商可以在本轮被写成「已选定」。
- 华为云盘古是本轮**唯一**三门槛都有公开书面文本可引用的候选，但其服务协议**明文禁止输入商业秘密 / 具有商业权益的数据**——零件图普遍涉密（ADR-0005），因此不能作为 MVP 提取引擎，记入排除名单。
- 阿里云百炼、腾讯云混元、火山方舟、百度千帆在 G1/G2 上有可用书面条款（部分有条件），**G3（可签 DPA）公开文本均未覆盖到本产品**，不能记「通过」。
- 智谱默认 API、DeepSeek、Kimi 开放平台协议、讯飞、MiniMax 在 G2 上未过或证据冲突，一票否决。
- 识别效果对比与最终选型 **blocked**：缺票 01 样本，且通过门槛的可用候选集合在 G3 书面确认前为空（华为因禁传商业秘密不可用）。

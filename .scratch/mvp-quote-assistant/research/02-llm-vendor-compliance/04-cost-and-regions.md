## 计费方式（各家公开页一致的部分）

视觉理解普遍按 **token** 计费，不是「一张图一个固定价」。单张费用：

```
单张费用 ≈ (图像折算 token + 提示词 token) × 输入单价 + 输出 token × 输出单价
```

图像折算随分辨率、切图、PDF 渲染 DPI、是否高清档而变。没有真实样本就不能把「平均每张 X 元」写进结论。

阿里云百炼对多数视觉模型给出的公开公式（https://help.aliyun.com/zh/model-studio/vision-model/）：

```
每张图片 token 数 = h × w / (32 × 32) + 2
```

多数模型单图最高 1600 万像素。公式示例（**不是实测**）：

| 假设像素（宽×高） | 按上式图像 token | 说明 |
|-------------------|------------------|------|
| 1024 × 1024 | 1 026 | 低分辨率示意 |
| 2480 × 3508（约 A4 / 150dpi 量级） | 8 502 | 扫描件常见量级的示意，**不是**本仓库任何样本 |
| 3508 × 4961（约 A4 / 300dpi 量级） | 16 998 | 更高清示意；接近或超过部分模型上限时会被缩小，实际 token 以响应为准 |

加上提示词与结构化输出后，单张输入通常还要再加数百到数千 token。下表「公式示意」只把图像 token 代入刊例输入价，**不含**提示词和输出。

## 阿里云 OSS 区域（本产品已定存储）

spec / ADR-0005：零件图存阿里云 OSS；大模型与 OSS 宜同一境内区域，避免图纸跨区流动的额外合规解释。

OSS 中国大陆公共云地域（摘录，完整表见官方）：

来源：https://help.aliyun.com/zh/oss/user-guide/regions-and-endpoints

| 地域 | 地域 ID | 与百炼北京对齐 |
|------|---------|----------------|
| 华北2（北京） | `cn-beijing` | **可对齐**：百炼中国站公开地域含华北2（北京） |
| 华东1（杭州） | `cn-hangzhou` | 百炼公开列表**未**把杭州列为模型服务地域；OSS 放杭州、推理走北京 = 境内跨区 |
| 华东2（上海）等其他大陆地域 | 各 `cn-*` | 同上，境内跨区，不是出境，但仍有合规解释成本 |
| 中国香港 `cn-hongkong` | 不计入大陆对齐 | 与 G1「境内/大陆」口径不一致 |
| 新加坡 / 弗吉尼亚 / 法兰克福 / 东京 | 出境 | 百炼 6.2.8 明确可能构成出境 |

**本轮建议（不是选定供应商）：** 若后续补齐 G3 后仍走阿里云百炼按量视觉 API，OSS Bucket 与百炼调用都应锁 **华北2（北京）**，禁止用境外 base_url。这是区域对齐，不是 ADR 选型。

## 其他供应商 vs OSS

| 供应商 | 公开区域结论 | 与 OSS 对齐 |
|--------|--------------|-------------|
| 腾讯云混元 | 处理地点「中华人民共和国境内」（条款 2.13） | 境内，但是**跨云**；不是 OSS 同地域内网。对齐只能做到「都不出境」，做不到「同一云同一 region」 |
| 百度千帆 | 客户可指定存储区域 | 未核到默认 = 北京或与 `cn-beijing` 同城。跨云 |
| 火山方舟 | 许可限大陆；处理地未在豆包协议写死 | 区域对齐**无法**在本轮写成「已对齐」 |
| 华为云盘古 | 输入在境内处理 | 跨云；且已被使用限制排除 |
| 其余 | 门槛未过 | 不做对齐承诺 |

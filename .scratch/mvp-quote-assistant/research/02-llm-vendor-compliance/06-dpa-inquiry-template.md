```
主题：书面确认 — 多模态推理 API 的数据处理地点、不训练承诺与 DPA

我们计划在中国大陆境内的 SaaS 中，将客户机加工零件图（PDF/图片，通常受 NDA 约束）经多模态大模型做结构化提取。需要贵司对下列事项给出可引用的书面答复（适用的产品名称、SKU、地域、法律主体须写明）：

1. 数据处理地点
   客户通过【产品名称 / 按量推理 API】提交的输入（含图像）及模型输出，是否仅在中华人民共和国大陆境内存储与处理？
   请列出必须开通的地域 / endpoint，以及哪些地域会导致出境。

2. 不用于模型训练
   是否书面承诺：上述输入与输出不用于预训练、微调、再训练或改进贵司基础模型？
   请指出条款编号。是否存在 opt-in 授权、数据回流、Coding Plan / 个人版等会推翻该承诺的 SKU？请列出我们必须避开的 SKU。

3. 数据处理协议（DPA）
   贵司中国站主体是否可与我们签署适用于该推理 API 的数据处理协议 / 数据处理附则？
   请提供模板或签署路径。国际站 DPA、其他云产品的 DPA 不能代替。

4. 涉密图纸
   服务协议是否禁止输入商业秘密或「具有商业权益的数据」？若禁止，企业合同能否删除或改写该条，使 NDA 约束下的零件图可以上传？

5. 与对象存储的区域
   我们的对象存储计划使用阿里云 OSS 华北2（北京）。请确认贵司推理服务是否可固定在北京或等价的大陆地域，避免图纸跨区。

请用 PDF 或正式邮件回复，并注明版本日期。口头或仅「销售介绍」页不能作为我们的合规证据。
```

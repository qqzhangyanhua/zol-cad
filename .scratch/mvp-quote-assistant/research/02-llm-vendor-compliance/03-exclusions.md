# 排除名单

**用途：** 日后有人重提某家供应商时，先读本页再决定要不要重开门槛核验。  
**依据：** 仅 `02-hard-gates-matrix.md` 与 `evidence/` 中的书面条款。

排除分两类，不要混：

1. **门槛排除** — G1 / G2 / G3 任一「未过」或「证据不足」且在补齐书面证据前不得进入识别对比。
2. **使用限制排除** — 三门槛书面齐，但合同禁止本产品的实际载荷（涉密零件图）。

| ID | 供应商 | 排除门槛 | 一句话原因 | 若要重提必须补什么 |
|----|--------|----------|------------|-------------------|

| C7 | DeepSeek 开放平台 | G2 | 隐私政策（适用范围含 API）写明输入输出可用于模型训练，仅提供产品内 opt-out | 开放平台协议出现肯定句「API 输入输出不用于训练」，且隐私政策不再覆盖 API 或与之冲突被废止 |

## 使用限制排除

| ID | 供应商 | 条款 | 为什么挡死本产品 |
|----|--------|------|------------------|
| C5 | 华为云盘古 | 《盘古大模型服务协议》2.1(8)：不得「向我们发送或输入您的或者任何第三方的商业秘密或具有商业权益的数据」。https://www.huaweicloud.com/declaration/tsa-pglm.html | ADR-0005：机加工客户零件图普遍涉密、常有 NDA。把图交给盘古推理会直接违反该条。三门槛通过不能覆盖这条禁令。 |

火山方舟《数据授权使用协议》也有「不应提供保密信息或商业秘密」的表述。那份协议是 **G2 的除外授权**，不是默认豆包推理合同。默认路径若将来 G1/G3 补齐，仍须法务确认默认推理合同是否含同类禁令；在书面确认前不要假设「默认可传涉密图」。

## 明确不是排除理由的东西

- 识别率高低 — 本轮没有样本，也不得用识别率让未过门槛者复活。
- 价格高低 — 成本见 `04`，不构成门槛排除。
- 「国内大厂」品牌 — 不是书面条款。
- 国际站 DPA、Coding Plan / Token Plan 个人版 / 消费级 App 的宣传句 — 不能用来推翻上表。

## 重提检查单

1. 新文本是否仍是**该产品、该站点、该 SKU**（按量 API vs 订阅 vs App）？
2. 是否同时覆盖 G1、G2、G3，每条都有 URL + 引文？
3. 是否仍禁止输入商业秘密 / 要求另签数据授权才能「不训练」？
4. 通过后再进入 `05`，不得跳过。

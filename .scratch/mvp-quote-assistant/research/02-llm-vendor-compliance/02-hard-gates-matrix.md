# 三条硬门槛判定矩阵

**状态：** 已按公开书面条款判定；G3 对多数候选仍为「证据不足」  
**顺序：** 本表先于 `05-recognition-comparison.md`。识别列不得回填本表。

判定取值：

- **通过** — 有可引用的书面条款，语义覆盖该门槛。
- **有条件通过** — 书面条款存在，但必须落实条款里写明的前置条件；条件未落实前不得当选定依据。
- **未过** — 书面条款明确相反，或明确授权将客户数据用于训练/改进模型。
- **证据不足** — 公开文本覆盖不到本产品 / 本门槛，或帮助页与协议冲突。**不得记通过。**

## C1 阿里云百炼

**G1 有条件通过。** 《阿里云百炼服务协议》6.2.8：「根据您与阿里云协商一致，阿里云将在您选定的阿里云百炼服务及模型服务所在国家或地区处理客户业务数据。……如您基于自身业务目的需要选择在中华人民共和国境外的阿里云百炼服务及模型服务处理客户业务数据，可能会导致您的客户业务数据出境。」  
来源：https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20230728213935489/20230728213935489.html  

条件：账号与调用必须锁在中国大陆地域（公开文档列出华北2（北京）为中国站地域之一）。选新加坡 / 弗吉尼亚 / 法兰克福 / 东京即不满足 G1。帮助页：「目前提供以下地域的模型服务：华北2（北京）、美国（弗吉尼亚）、国际（新加坡）、德国（法兰克福）和日本（东京）地域」。  
来源：https://help.aliyun.com/zh/model-studio/what-is-model-studio  

6.2.9：若走三方模型 API，「客户业务数据的处理……以您和三方模型 API 服务商在相关服务协议中的约定为准」。MVP 若用百炼，应锁定阿里云自研千问视觉理解，不要默认转售的境外模型。

**G2 有条件通过。** 6.2.5：「我们不会在未获您授权的情况下使用您的对话数据训练我们的模型。」同上服务协议。  
帮助页 FAQ：「使用百炼按量付费 API 和 Token Plan 团队版时，不会将您的数据用于模型训练。」并写明 Token Plan 个人版与 Coding Plan **没有**这条承诺；Coding Plan「模型输入及模型生成的内容将用于服务改进与模型优化」。  
来源：https://help.aliyun.com/zh/model-studio/what-is-model-studio  

条件：只用**按量付费 API**（或 Token Plan 团队版，若将来确认其覆盖视觉理解且合同未改）。禁止用 Coding Plan / Token Plan 个人版跑零件图。

**G3 证据不足。** 检索到的《Data Processing Addendum》挂在阿里云**国际站**（https://www.alibabacloud.com/help/zh/legal/latest/fe2cxg），主体不是中国站百炼。中国站能公开找到的「数据处理附录」示例是 Salesforce on Alibaba Cloud，不覆盖百炼。百炼「相关协议」页列出服务协议 / SLA / 体验功能说明等，**没有**百炼 DPA。  
来源：https://help.aliyun.com/zh/model-studio/related-agreements  

## C2 火山方舟 / 豆包

**G1 证据不足。** 《豆包模型服务协议》2.1 授予的使用许可「仅在中国大陆地区范围内」，这是许可地域，不是「输入存储/处理在大陆」的陈述。同平台《数据保护协议》写明默认在中国大陆存储处理，但该文档路径属于**云通信**产品（https://www.volcengine.com/docs/6391/67493），不能自动覆盖方舟推理。方舟产品协议本身未见等价一句。

**G2 有条件通过。** 豆包模型服务协议 3.1：「服务将不使用您提交给服务或使用服务输出的内容训练、重新训练或改进基础模型。但您同意我们单独的《数据授权使用协议》的情况除外。」  
来源：https://www.volcengine.com/docs/82379/1142195  

条件：不得签署 / 开通会推翻 3.1 的《数据授权使用协议》或数据回流授权。另：该授权协议草稿含「不应……提供任何保密信息或商业秘密」（https://www.volcengine.com/docs/82379/2047627）——即使 G2 成立，涉密零件图仍要法务看能不能走默认推理合同。

**G3 证据不足。** 公开 DPA 文本见于云通信，未见「方舟 / 豆包模型服务适用且可签」的书面句。

## C3 百度千帆

**G1 证据不足。** 《百度智能云用户服务协议》写「您可以指定您的内容所存储的区域」，不是「千帆推理输入默认在中国大陆」。千帆用户协议未检索到处理地点 = 境内的专条。

**G2 通过。** 千帆用户协议：「为免疑义，我们不会使用您的输入和模型输出数据、上传的知识文档、数据集进行训练，也不会将您的数据集与任何第三方共享。」  
来源：https://cloud.baidu.com/doc/qianfan/s/Cmh4stmpy  

注意同协议 13.2 授权将相关数据用于「服务性能优化、系统故障排查及风险控制管理」，这不是「训练模型」的同义句，但安全问卷里可能被追问；不单独构成 G2 未过。

**G3 证据不足。** 协议概述页未列出可下载的千帆 DPA。检索到的「数据保密协议」属于千帆 AI 原生应用商店服务商，不是推理 API 客户 DPA。

## C4 腾讯云混元

**G1 通过。** 《大模型服务条款》2.13：「本服务条款下的数据处理地点为中华人民共和国境内。」  
来源：https://cloud.tencent.com/document/product/301/97822  

**G2 通过。** 同条款 4.2：「除另行获取您的授权同意外，腾讯云不会将您输入的内容用于开发或改进本服务的算法、模型等。」

**G3 证据不足。** 能检索到的 DPSA 在腾讯云**国际站**（如 https://www.tencentcloud.com/zh/document/product/301/17347）。中国站混元「相关协议」列出 SLA / 服务条款 / 隐私政策，未见中国站混元 DPA。不得用国际站 DPSA 代替。

文档提示混元能力将迁往 TokenHub；TokenHub 企业版若另有协议，G1/G2/G3 必须按**实际下单的那份**重核，不得沿用本表旧链。

## C5 华为云盘古

**G1 通过。** 《盘古大模型服务协议》4.3：「我们将在【中华人民共和国境内】处理「您的输入」，在完成推理任务后，「您的输入」将立即删除。」个人信息：「将在【中华人民共和国】境内处理」。  
来源：https://www.huaweicloud.com/declaration/tsa-pglm.html  

**G2 通过。** 3.6：「除本协议或其他协议另有约定或相关法律法规要求以外，我们不会使用「您的输入」来开发或改进本服务。」

**G3 通过。** 4.2：「我们仅根据您与我们签署的华为云数据处理附则处理「您的输入」中的个人数据。」附则全文公开：https://www.huaweicloud.com/declaration/sa-dpa.html  

**仍不得选定。** 2.1(8) 禁止「向我们发送或输入您的或者任何第三方的商业秘密或具有商业权益的数据」。ADR-0005 认定机加工零件图普遍涉密。三门槛齐 ≠ 合同允许上传零件图。见 `03-exclusions.md`。

## C6 智谱 bigmodel.cn

**G1 证据不足。** 隐私政策：「我们在中国境内运营中收集和产生的个人信息存储在中国境内。」覆盖的是个人信息，不是零件图业务数据的处理地。  
来源：https://docs.bigmodel.cn/cn/terms/privacy-policy  

**G2 未过。** 用户协议：「改进我们的产品和服务（包括使用匿名数据进行机器学习或模型算法训练）……无需另行征得您的同意。」另：「我们可能利用您使用大模型平台或平台内模型过程中产生的数据，定位、维护和优化我们的产品和服务」。并授予对非个人信息「永久、免费的许可使用……及可再许可第三方」。  
来源：https://docs.bigmodel.cn/cn/terms/user-agreement  

GLM Coding Plan 团队套餐写「数据默认不用于模型训练」，但该套餐是编码工具订阅，协议禁止把额度接到自建后端 API。不能拿 Coding Plan 的句子给读图取数 API 过 G2。

**G3 证据不足。** 未见 bigmodel.cn 推理 API 的可签 DPA 文本。

## C7 DeepSeek 开放平台

**G1 证据不足。** 隐私政策：「将在境内运营过程中收集和产生的您的个人信息存储于中华人民共和国境内。」仍是个人信息，不是图纸业务数据专条。  
来源：https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html  

**G2 未过。** 同隐私政策（适用范围含 API）：「我们可能会将服务所收集的输入及对应输出，用于 DeepSeek 模型训练和服务的优化。」退出方式是产品内关闭「数据用于优化体验」——这是 opt-out，不是「默认不训练」的书面承诺。开放平台服务协议第 4 条没有「不会用于训练」的肯定句。  
开放平台协议：https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html  

**G3 证据不足。**

## C8 Kimi 开放平台（中国站）

**G1 证据不足。** 隐私政策：「我们将您的个人信息存储于中华人民共和国境内。」同上，覆盖个人信息。  
来源：https://platform.kimi.com/docs/agreement/userprivacy  

**G2 证据不足（按未过处理）。** 帮助中心：「通过 API 提交的用户数据……不会用于训练或改进 Kimi 的模型。」https://www.kimi.ai/zh-hans/help/kimi-api/api-data-security  
服务协议：「为了提升您使用本服务的体验，您授予我们一项免费的使用权，以在法律允许的范围内将您输入输出之内容及反馈用于模型服务优化。」https://platform.kimi.com/docs/agreement/modeluse  

帮助页与合同冲突。门槛要求书面承诺；冲突时以合同为准，且不得把帮助页记成通过。

**G3 证据不足。** 帮助页只说「联系销售团队了解企业级安全解决方案」，不是可签 DPA 的书面句。

## C9 讯飞星火

**G1 证据不足。** 星火隐私政策讨论存储期限与服务器，未见「客户输入仅在中国大陆」的专条可稳定引用。  
来源：https://www.xfyun.cn/doc/spark/SparkPrivacyPolicy.html  

**G2 未过。** 讯飞开放平台隐私政策：可能对技术处理后的信息「进行匿名化或去标识化的学术研究或统计分析（包括使用匿名化或去标识化后的语音信息进行模型算法的训练）」。  
来源：https://www.xfyun.cn/doc/policy/privacy.html  

**G3 证据不足。**

## C10 MiniMax

**G1 证据不足。** 未核到「推理输入仅在中国大陆」的产品专条。

**G2 未过。** 《MiniMax 隐私政策》1.7.2：「在经安全加密技术处理、去标识化且无法重新识别特定个人的前提下，我们可能会将输入内容、输出内容、行为信息进行分析和用于模型训练」。  
来源：https://agent.minimaxi.com/doc/zh/privacy-policy.html  

**G3 证据不足。** 用户协议里的 DPA 专节针对 **Agent 任务数据**，不是「开放平台视觉推理 API 客户可签 DPA」的书面证明。
